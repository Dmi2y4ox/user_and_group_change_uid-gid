# Скрипт изменения UID и GID пользователя с изменением прав
## Авторство
> [!IMPORTANT]  
> Данный скрипт является исправленной версией скрипта, который был разработан автором данной статьи https://habr.com/ru/articles/81715/.

## Изменения
В скрипт были внесены следующие изменения:
1. Устаревший `$(tempfile)` был изменен на `$(mktemp)`;
2. Построчное написание кода для более удобного чтения.

## Как запустить скрипт
После скачивания скрипта разрешите права на выполнения файла с помощью команды:

`sudo chmod +x script.sh`

Далее отредактируйте переменные:
- user (укажите целевого пользователя для которого производятся изменения);
- new_uid (укажите желаемый uid пользователя);
- group (укажите целевую группу пользователя);
- new_gid (укажите желаемый gid пользователя).

> [!WARNING]
> Убедитесь, что новый uid и gid не заняты в вашей системе использую команду
>
> `cat /etc/passwd | grep <new_uid>:<new_gid>`

Если целевые uid и gid свободны, запустите скрипт используя команду 

`sudo bash script.sh`

> [!WARNING]
> Для выполнения скрипта необходимы привелегированные права пользователя!
